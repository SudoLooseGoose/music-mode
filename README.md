# Music Mode

A Linux music workspace combining Spotify, CAVA, and a retro cartoon TV powered by mpv.

Features include automatic cartoon channel switching, CRT effects, and playback synchronization with Spotify.

## Requirements

Bash, Spotify Flatpak, CAVA, Alacritty, mpv, FFmpeg, playerctl, socat, jq, and GNU coreutils.

Place your own video files in ~/Videos/MusicMode.

Run ./music-mode.sh to launch.

Window placement uses KDE Plasma KWin rules and must be configured separately.
